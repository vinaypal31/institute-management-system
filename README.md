# Institute Management System

A full-stack backend project built using FastAPI and PostgreSQL.

## Features

* JWT Authentication (Admin & Student)
* Role-Based Access Control
* Student & Course Management
* Attendance Tracking System
* Fee Management
* Email Notifications

## Tech Stack

* FastAPI
* PostgreSQL
* SQLAlchemy
* JWT Auth

## How to Run

1. Clone repo
2. Create `.env` file
3. Install dependencies
4. Run:
   uvicorn main:app --reload
